# Air Quality CO(GT) Prediction

Этот проект посвящён анализу и построению моделей для прогнозирования концентрации угарного газа (CO) на основе данных датасета [AirQualityUCI](https://archive.ics.uci.edu/ml/datasets/Air+Quality).

## Описание данных

- Набор данных содержит измерения различных газов и параметров воздуха, таких как CO, NOx, температура и влажность, с временными метками.
- Целевая переменная — концентрация CO (угарного газа), измеренная в мг/м³.

---

## Предобработка данных

- Загрузка данных из CSV с корректной обработкой дат и пропущенных значений.
- Удаление столбцов с большим количеством пропусков.
- Заполнение пропущенных значений методом прямого заполнения (forward fill).
- Масштабирование признаков с помощью StandardScaler.

---

## Анализ данных (EDA)

- Временные ряды концентрации CO.
- Корреляционный анализ признаков.
- Гистограммы, ящики с усами и парные зависимости для ключевых переменных.

---

## Построение моделей

Используются следующие регрессионные модели:

- Random Forest
- Gradient Boosting
- XGBoost
- LightGBM
- CatBoost

Для каждой модели рассчитываются метрики: RMSE, MAE и R².

---

## Ансамблирование

- Создан ансамбль моделей с помощью VotingRegressor для улучшения качества предсказаний.
- Метрики ансамбля сопоставимы с лучшими отдельными моделями.

---

## Выявление аномалий

- Использован алгоритм Isolation Forest для поиска выбросов в обучающих данных.
- Визуализация обнаруженных аномалий.

---

## Визуализация и интерпретация

- Сравнение предсказаний ансамбля с истинными значениями.
- Важность признаков (Random Forest).
- Диаграмма остатков (Residual plot).
- Таблица сравнения первых 10 предсказаний.
