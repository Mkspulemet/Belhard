# Домашняя работа №5 — Сравнение регрессоров на датасете California Housing

## 📌 Цель работы

Реализовать и сравнить не менее 5 моделей регрессии на реальном датасете. Оценить качество моделей с помощью метрик, выбрать наилучшую модель, сохранить её и визуализировать результаты.

---

## 📊 Используемый датасет

California Housing — встроенный датасет из библиотеки `sklearn.datasets`, включающий информацию об объектах недвижимости в Калифорнии. Каждая запись содержит:

- **MedInc** — средний доход в районе
- **HouseAge** — средний возраст домов
- **AveRooms** — среднее количество комнат
- **AveBedrms** — среднее количество спален
- **Population** — население
- **AveOccup** — среднее количество людей на домохозяйство
- **Latitude/Longitude** — географическое положение
- **MedHouseVal** — медианная стоимость домов (целевой признак)

---

- Масштабирование признаков: `StandardScaler`.
