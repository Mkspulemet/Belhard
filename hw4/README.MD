
📌 Описание
1. Цели проекта
Построить классификаторы для распознавания изображений цифр.

Сравнить качество различных моделей по метрикам:

Accuracy

F1 Score

ROC AUC

Настроить гиперпараметры для модели LightGBM с помощью Optuna.

Проверить обученную модель на внешних изображениях из папки digits/.

🔧 Используемые технологии
Python 3.10+

Jupyter Notebook

Библиотеки:

scikit-learn

matplotlib, seaborn

xgboost, lightgbm, catboost

optuna

tensorflow.keras.datasets (для загрузки MNIST)

PIL (обработка изображений)

🚀 Основные этапы
1. Загрузка и подготовка данных
Используется 10 000 изображений из MNIST для обучения и 2 000 для теста.

Все изображения масштабируются и приводятся к векторному виду размерности 784 (28×28).

Стандартизация признаков с помощью StandardScaler.

2. Визуализация выборки
Отображаются первые 10 изображений из обучающей выборки с соответствующими метками.

3. Обучение моделей
Используются следующие классификаторы:

Gradient Boosting

CatBoost

AdaBoost

Extra Trees

QDA

LightGBM

K Neighbors

Decision Tree

XGBoost

Dummy Classifier (базовая модель)

SVM (Linear)

Оцениваются метрики:

Accuracy

F1 Score (macro)

ROC AUC (multi-class OVO)

4. Визуализация результатов
Графики сравнения моделей по всем метрикам.

5. Оптимизация LightGBM с помощью Optuna
Поиск оптимальных гиперпараметров по F1-метрике.

6. Повторное обучение лучшей модели
Модель LightGBM переобучается с найденными параметрами.

7. Проверка на внешних изображениях
Внешние изображения берутся из папки digits/:

Либо собственные сгенерированные (шрифт PIL),

Либо реальные из MNIST.

Производится масштабирование и предсказание.


Если хотите протестировать внешние изображения, положите .png файлы в папку digits/ (размер 28x28, цветовая схема: черная цифра на белом фоне).

📝 Примеры вывода
Предсказания для изображений из папки digits:
0.png -> Предсказано: 0
1.png -> Предсказано: 1
...
9.png -> Предсказано: 9

⚠️ Важно
Если используете не MNIST-цифры, а, например, сгенерированные через PIL (шрифт ImageFont.load_default()), модель может давать некорректные предсказания — она обучалась на рукописных изображениях.
